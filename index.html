Features

核心能力

从推理循环到交互体验，每一层都是为终端场景重新设计的。

双协议 LLM 适配

Anthropic Messages 与 OpenAI Chat Completions 双格式原生支持，可混合配置：规划用一个模型，执行用另一个。

多 Agent 编排

内置 general-purpose / Explore / Plan 三类子 Agent，支持自定义定义，进程级 Hub 管理并发、前后台调度与中断。

Hooks 生命周期自动化

PreToolUse / PostToolUse / UserPromptSubmit / Stop 四个节点可挂任意 shell 脚本，对齐真实 Claude Code。

可插拔 MCP

内置 Bash / Read / Write / Edit / Glob / Grep / WebFetch / TodoWrite，并可桥接任意外部 MCP server。

上下文自动压缩

token 数逼近窗口上限时自动生成摘要替换旧消息，长会话也不会突然断档。

CLAUDE.md 记忆机制

每轮重新读盘注入、子目录动态加载、@path 递归导入，跨会话记忆同样开箱即用。

原生 ratatui TUI

流式 markdown、语法高亮、工具调用实时展示、子 Agent 聚合面板，交互体验为终端而生。

Profile 分组配置

provider / model / base_url / api_key 具名分组，多供应商配置并存，随时切换。

会话持久化

-c 续上次会话，--resume <id> 恢复任意历史会话。

自定义 Slash 命令

兼容 ~/.claude/commands/*.md 与项目级命令，六层路径合并加载。

中 / 英双语

界面文案运行时切换语言，自动检测系统 locale，也可在配置中显式指定。

零遥测

仅在显式调用 LLM / WebFetch / MCP 时才出网，没有任何隐式埋点或崩溃上报。

Architecture

10 个 crate 的 Rust workspace

单一 wyj-code 二进制，职责分层清晰：从上到下依次是入口、服务、核心、基础四层。

入口层 · Entry

crates/cli

二进制入口：组装全部 crate、解析 CLI 参数、启动 TUI / REPL / 单次问答模式

crates/tui · wyj-tui

ratatui 终端渲染：输入框、权限确认对话框、子 Agent 面板

服务层 · Services

crates/tools · wyj-tools

Read/Write/Edit/Bash/Glob/Grep/WebFetch/TodoWrite 等工具实现

crates/commands · wyj-commands

Slash 命令注册表与内置命令（/help、/compact 等）

crates/mcp · wyj-mcp

MCP 客户端桥接（stdio / http 传输）

crates/store · wyj-store

MCP / Skill / Plugin 安装元数据与市场客户端

crates/i18n · wyj-i18n

多语言资源与运行时语言切换

核心层 · Core

crates/core · wyj-core

Agent 推理循环、Session、HistoryStore、MemoryStore、ClaudeMdLoader、上下文压缩

基础层 · Foundation

crates/api · wyj-api

LLM Provider 抽象 trait + Anthropic/OpenAI 双格式实现，SSE 流式解析

crates/config · wyj-config

配置加载（~/.wyj-code/config.toml）、MCP 配置结构

Install

60 秒上手

克隆、构建、配置 API Key，直接开始对话。

# clone & build
git clone https://github.com/wangyooujin/wyj-code.git && cd wyj-code
./build.sh install && wyj-code --config-status

# set your API key
export WYJ_CODE_API_KEY=sk-...

# go
wyj-code

从 GitHub Releases 下载对应平台压缩包，解压后运行内置安装脚本，自动装入用户目录并配置 PATH，无需 sudo / 管理员权限。

# macOS / Linux
tar xzf wyj-code-*.tar.gz && cd wyj-code-*/ && ./install.sh

# Windows（在解压目录里）
install.bat

# 之后升级
wyj-code update
前往 Releases 页面下载 →

需要 Rust 1.80+ 工具链，构建 release 二进制并安装到 ~/.local/bin。

git clone https://github.com/wangyooujin/wyj-code.git
cd wyj-code
./build.sh install

# 卸载
./build.sh uninstall

直接用 cargo 跑起来，适合改代码调试。

# TUI 模式
cargo run

# 单次问答
cargo run -- -p "你的问题"

# headless REPL
cargo run -- --headless

# 查看配置状态
cargo run -- --config-status

Principles

设计原则

01

本地优先

没有隐式埋点、没有崩溃上报，配置与会话数据全部留在本机。

02

透明可控

每一次工具调用全程实时展示，敏感操作前弹权限确认，随时可以 ESC 打断。

03

协议中立

改一行 provider 配置即可在 Anthropic / OpenAI 之间切换，不锁定单一供应商。

04

零遥测

只有显式的 LLM / WebFetch / MCP 调用才会出网，没有任何后台上报。
