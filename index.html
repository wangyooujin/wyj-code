First Five Minutes

装好之后，这四件事都做得到

01

配好一个模型

首次启动自动打开配置面板，填入 API Key 即可。Key 只存本机，也可走环境变量，不落盘明文。

02

在你自己的仓库里问一个真问题

它会先读文件再回答，读取过程逐行展开给你看，不是凭空作答。

03

让它改一处你早就想改的东西

权限弹窗按 y 放行、d 拒绝——拒绝的信息也会回灌给它，让它换个思路。

04

挂上你自己的 MCP server

在 ~/.wyj-code/config.toml 加一段配置，它的工具就出现在模型可用的工具列表里。

Model Compatibility

我的模型能不能用

这张表按证据等级如实标注，而不是一律写「支持」。StaticOnly 意味着「我们从未在你的模型上实测过」——下面会告诉你怎么自己验证。

别信这张表，自己验一遍

装好之后，静态诊断是免费的；实测会发极少量最小请求，结果写入本机缓存，之后该模型在你的机器上就标记为「已实测验证」。

# 静态诊断，免费
wyj-code model doctor

# 实测兼容性（basic | full）
WYJ_CODE_PROBE_API_KEY=sk-... \
  wyj-code model doctor --probe basic

实测必须用临时 key

实测故意不读取配置文件里已保存的凭据，只认 WYJ_CODE_PROBE_API_KEY。需要你自己临时轮换一个——理由是探测请求要能证明「这个 key 能用」，而不是「配置文件里那串字符还在」。

Who Is This For

它适合谁，不适合谁

右边那一列同样重要——如果你正好属于它，现在就可以关掉这个页面。

你可能更适合它，如果

  • ·你本来就在终端里工作，希望 AI 的每一步都看得见，而不是收到一个成品 diff
  • ·你在用国内模型，需要一套统一工具链，而不是为每个厂商单独适配一遍
  • ·你在意工具链本身——愿意读源码、自己改工具链，甚至自己加一个模型适配
  • ·你需要定时任务、后台任务与多 Agent 协作，而不是只有一问一答

你可能不用换，如果

  • ·你需要开箱即用的图形界面，不想面对终端
  • ·你不想自己准备 API Key 并管理多模型配置
  • ·你依赖某个闭源产品特有的生态、托管能力和商业支持
  • ·你更在意「什么都不用管」，而不是「每一步都在你控制下」

Install

60 秒上手

一条命令完成下载、安装、配置 PATH，无需 sudo / 管理员权限。

macOS / Linux

curl -fsSL https://wangyooujin.github.io/wyj-code/install.sh | sh

Windows (PowerShell)

irm https://wangyooujin.github.io/wyj-code/install.ps1 | iex

脚本自动识别平台架构、拉取 GitHub 最新 Release、校验 sha256 后装入用户目录；之后可用 wyj-code update 升级。

手动从 GitHub Releases 下载对应平台压缩包，解压后运行内置安装脚本——这正是上面一键脚本在背后做的事，适合不想执行 curl | sh 的场景。

# macOS / Linux
tar xzf wyj-code-*.tar.gz && cd wyj-code-*/ && ./install.sh

# Windows（在解压目录里）
install.bat

# 之后升级
wyj-code update
前往 Releases 页面下载 →

需要 Rust 1.80+ 工具链，构建 release 二进制并安装到 ~/.local/bin。

git clone https://github.com/wangyooujin/wyj-code.git
cd wyj-code
./build.sh install

# 卸载
./build.sh uninstall

直接用 cargo 跑起来，适合改代码调试。

# TUI 模式
cargo run

# 单次问答
cargo run -- -p "你的问题"

# headless REPL
cargo run -- --headless

# 查看配置状态
cargo run -- --config-status
