Features

核心能力

从推理循环到交互体验，每一层都是为终端场景重新设计的。

国内模型可信运行时

GLM、MiniMax、Kimi、DeepSeek、Qwen、豆包按能力来源和置信度适配；静态兼容与 live verified 明确分开。

可控的多 Agent 协作

进程级 Hub 管理并发、前后台调度、follow-up、interrupt、retry-last 与落盘 trace，控制消息只在安全边界注入。

Hooks 生命周期自动化

PreToolUse / PostToolUse / UserPromptSubmit / Stop 四个节点可挂任意 shell 脚本，对齐真实 Claude Code。

可插拔 MCP

内置 Bash / Read / Write / Edit / Glob / Grep / WebFetch / TodoWrite，并可桥接任意外部 MCP server。

上下文自动压缩

token 数逼近窗口上限时自动生成摘要替换旧消息，长会话也不会突然断档。

CLAUDE.md 记忆机制

每轮重新读盘注入、子目录动态加载、@path 递归导入，跨会话记忆同样开箱即用。

证据化自进化

v1.5.5 用 Episode、可验证 Memory、人工审批 Rule/Skill 候选和原子回滚形成透明闭环；Web/MCP 外部上下文默认隔离。

原生 ratatui TUI

流式 markdown、语法高亮、工具调用实时展示、子 Agent 聚合面板，交互体验为终端而生。

能力诊断与安全 Key 引用

model doctor 展示 vendor/protocol/能力来源；api_key_env 避免运行时 secret 被写回配置。

Checkpoint / Rewind / Branch

保留真实 Git index，按 conversation/files/both 恢复，并从任意 checkpoint 创建不影响原会话的新分支。

自定义 Slash 命令

兼容 ~/.claude/commands/*.md 与项目级命令，六层路径合并加载。

中 / 英双语

界面文案运行时切换语言，自动检测系统 locale，也可在配置中显式指定。

Fail-closed OS Sandbox

macOS Seatbelt + 受控域名代理、Linux bubblewrap；headless、schedule 与 SubAgent 无 UI 时拒绝隐式放行。

Computer-use 桌面控制

模型可观察并操控本机 GUI（macOS / Windows）；v1.5.5 允许 headless/daemon 安全执行截图、窗口枚举和元素检查，点击、输入、滚动及未知动作仍失败关闭。

Workflow + 隔离 Worktree

DAG 支持并行、预算、审批、暂停、重试与取消；有写权限的编码节点从脏工作区 checkpoint 自动创建独立 worktree，变更需显式 review/accept。

ACP / daemon 控制面

stdio ACP 与本地 TCP daemon 共享前端无关事件协议；daemon session 跨连接存活，可重连、列出、提交、打断、rewind、branch 和关闭。

Plugin Runtime + LSP

插件可事务式贡献 hooks、styles、themes、channels、LSP、monitors 与 settings；真实 workspace/symbol 与本地索引合并。

本地 Review 证据

review run 对 commit/PR diff 生成可审计 JSON，处理 rename、空格路径和 binary，并对 secret evidence 脱敏。

Jev 决策 API（v1.5.13）

TypeSafe System One 决策模型作独立 tool：意图路由 / 分类 / guardrails / 置信度标注，输出结构化 answers + probabilities；/decision slash 命令做连通性诊断，三层硬封顶（state 大小 / question 数 / 日预算）防失控。

Principles

设计原则

01

本地优先

没有隐式埋点、没有崩溃上报，配置与会话数据全部留在本机。

02

透明可控

每一次工具调用全程实时展示，敏感操作前弹权限确认，随时可以 ESC 打断。

03

协议中立

vendor 与 wire protocol 分离，同一兼容协议可服务不同厂商，不把模型名称猜测当成最终事实。

04

零遥测

只有显式的 LLM / WebFetch / MCP 调用才会出网，没有任何后台上报。

v1.5.16 最新公开版

后台任务可见性与自动续跑：此前后台 subagent 的结果只暂存到下一条用户消息才注入、后台 shell 更只返回一个 bash_N id 靠模型自己轮询 BashOutput，两条路都会停在等用户输入——"派完活就不动了"。现在主循环 idle 钩子检测到后台任务完成即自动起新 turn 把结果喂回主 Agent，多任务同帧完成合并成一轮避免连续多次 LLM 往返；spawn_agent_turn 新增自动唤醒模式（text: Option<String>），reminder 作为这一轮唯一 user 输入而非伪装成用户发言，聊天流只显示可读的 ⚙ 系统提示。ESC 中断后暂停自动唤醒（"我明明打断了怎么又跑起来"），直到你发下一条消息才恢复。新增底部后台任务面板：有 run_in_background 任务时自动出现，BashSessionManager 有完整输出缓冲但 TUI 侧此前一行代码都没接，所有后台任务在界面上完全不可见——现在列表实时显示 id / 命令 / 状态 / 耗时 / 退出码，Enter 展开实时输出、PageUp/PageDown 翻页看历史（默认贴底跟随）、按 k 终止进程组；任务退出时输出尾部自动回显给模型。新增 /shells [id] 命令手动查看已结束任务。两个面板互斥时按用户焦点优先（子 Agent 与后台 shell 常同时跑，固定先后会让其中一方永远看不见也按不了 k），跨区链条 Chat ↓ → Todos ↓ → SubAgents ↓ → Shells。新增 BackgroundJob::tail() 只读快照 API——面板每帧读输出不能推进 BashOutput 的增量游标，否则两者互相抢对方的内容。三个坑都做了防护：退出时 kill_all() 会把全部 job 翻成 Exited(-1)，should_quit 守卫拦住误唤醒；后台任务跨轮次保留只在会话级重置才清（否则 dev server 会在你发新消息时从面板凭空消失）；任务列表全部完成后收成一行摘要，不再以 2 行折叠面板一直挂到下一条消息。

Prompt cache 自我击穿修复：Provider 的 system 参数从 &str 改为 &SystemPrompt<_'>（新增 stable / volatile 两段）。此前整个 system 压成一个字符串、Anthropic 侧只能发单个 text 块且断点打在块尾，而 system 里混了大量每轮会变的内容（工具可用性、模型兼容 suffix、子目录 CLAUDE.md reminder、Project Brief），任何一项变化都让整段 1.6k~5k token 全价重算——旧注释"reminder 只增不减、前缀仍可缓存"是错的，追加在断点之后同样改写前缀哈希。现在 stable 段末尾打 cache_control: EPHEMERAL、volatile 段不打（断点预算 3，仍在上限 4 内）；Project Brief 改按 MEMORY_SNAPSHOT_REFRESH_TURNS = 10 分桶缓存，缓存抖动降到 1/10。【源码级破坏】自定义 Provider 实现需改签名（辅助 LLM 调用用 SystemPrompt::stable_only(...) 一行迁移）。【API 移除】compact::COMPACT_TRIGGER_BUFFER 常量改为函数。

一批"看起来在工作、实际静默失效"的缺陷修复：persist_cap 的两条 JSON 上限从上线起从未生效——ToolUse.input 与 tool_result 的 Blocks 被 to_string 后做字符串级截断，插入的 [truncated N bytes] 标记使 JSON 必然解析失败，而失败分支是 if let Ok(...) 静默吞掉，超限的 Edit/Write 参数与 Bash 输出原样进请求体并落盘；改为 shrink_json_to_budget() 按"最长 string 叶子"裁剪并保持合法 JSON。子 Agent 权限比主 Agent 更严：父级处于 Bypass(AutoApprove) 时子 Agent 落回默认 Prompt，而它没有审批 UI，Prompt + 无 UI 通道在 PermissionPolicy::evaluate 与 confirm_tool 两道关卡上 fail-closed，Bash/Edit/Write 被全量拒掉；改为委派本身已在父级审批过、子 Agent 继承 AutoApprove，同时加护栏：只有被委派类型可能拿到副作用工具时才弹一次审批（Explore/Plan 零打扰）。孤儿 tool_use 兜底配对：模型写参数被 max_tokens 截断时留下无配对 tool_result，该历史一旦落盘会让每次 --resume 永久 400 且用户无法自愈；现在合成 is_error: true 的兜底结果。Checkpoint 配置被 TUI 侧覆盖：7 处裸 new() + attach_agent_session 覆盖装配好的 store，切换一次模型后 checkpoint 不再封顶、快照不走 CAS 去重（同 session 从 <5 MB 退回 200 MB 量级）；改为进程级 set_checkpoint_config() + configured()。压缩用量漏记：压缩本身的 LLM 往返被丢弃，/cost 系统性低估真实花费；悬空 cwd panic：工作目录被删时 current_dir() 返回 Err 而调用点 .unwrap() panic，改为明确中文错误并刻意不做 $HOME 兜底（cwd 决定 project root 与会话归属，静默换目录比报错危险）；/context 占用率不再写死 200K；agent.compacted 文案从硬编码中文改走 i18n。删除 4 个从未有任何消费点的幻象配置（checkpoint_bytes_per_session / cas_total_bytes / cas_gc_on_start / checkpoint_ttl_days，迁移成本为零）——但需注意 cas/ 与 *.checkpoints/ 至今仍无任何回收路径。
