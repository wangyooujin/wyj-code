Features

核心能力

从推理循环到交互体验，每一层都是为终端场景重新设计的。

国内模型可信运行时

GLM、MiniMax、Kimi、DeepSeek、Qwen、豆包按能力来源和置信度适配；静态兼容与 live verified 明确分开。

可控的多 Agent 协作

进程级 Hub 管理并发、前后台调度、follow-up、interrupt、retry-last 与落盘 trace，控制消息只在安全边界注入。

Hooks 生命周期自动化

PreToolUse / PostToolUse / UserPromptSubmit / Stop 四个节点可挂任意 shell 脚本，对齐真实 Claude Code。

可插拔 MCP

内置 Bash / Read / Write / Edit / Glob / Grep / WebFetch / TodoWrite，并可桥接任意外部 MCP server。

上下文自动压缩

token 数逼近窗口上限时自动生成摘要替换旧消息，长会话也不会突然断档。

CLAUDE.md 记忆机制

每轮重新读盘注入、子目录动态加载、@path 递归导入，跨会话记忆同样开箱即用。

原生 ratatui TUI

流式 markdown、语法高亮、工具调用实时展示、子 Agent 聚合面板，交互体验为终端而生。

能力诊断与安全 Key 引用

model doctor 展示 vendor/protocol/能力来源；api_key_env 避免运行时 secret 被写回配置。

Checkpoint / Rewind / Branch

保留真实 Git index，按 conversation/files/both 恢复，并从任意 checkpoint 创建不影响原会话的新分支。

自定义 Slash 命令

兼容 ~/.claude/commands/*.md 与项目级命令，六层路径合并加载。

中 / 英双语

界面文案运行时切换语言，自动检测系统 locale，也可在配置中显式指定。

Fail-closed OS Sandbox

macOS Seatbelt + 受控域名代理、Linux bubblewrap；headless、schedule 与 SubAgent 无 UI 时拒绝隐式放行。

Computer-use 桌面控制

模型截图观察桌面、合成鼠标点击拖拽与键盘输入操控本机 GUI（macOS / Windows），官方端点与第三方 Anthropic 协议兼容端点均可用。

Workflow + 隔离 Worktree

DAG 支持并行、预算、审批、暂停、重试与取消；有写权限的编码节点从脏工作区 checkpoint 自动创建独立 worktree，变更需显式 review/accept。

ACP / daemon 控制面

stdio ACP 与本地 TCP daemon 共享前端无关事件协议；daemon session 跨连接存活，可重连、列出、提交、打断、rewind、branch 和关闭。

Plugin Runtime + LSP

插件可事务式贡献 hooks、styles、themes、channels、LSP、monitors 与 settings；真实 workspace/symbol 与本地索引合并。

本地 Review 证据

review run 对 commit/PR diff 生成可审计 JSON，处理 rename、空格路径和 binary，并对 secret evidence 脱敏。

Architecture

12 个 crate 的 Rust workspace

单一 wyj-code 二进制，职责分层清晰：从上到下依次是入口、服务、核心、基础四层。

入口层 · Entry

crates/cli

二进制入口：组装全部 crate、解析 CLI 参数，启动 TUI / REPL / Workflow / ACP / daemon / Review

crates/tui · wyj-tui

ratatui 终端渲染：输入框、权限确认对话框、子 Agent 面板

服务层 · Services

crates/tools · wyj-tools

Read/Write/Edit/Bash/Glob/Grep/WebFetch/TodoWrite 等工具实现

crates/computer · wyj-computer

Computer-use 系统层：截图 + 鼠标键盘输入合成，坐标缩放数学独立可测

crates/commands · wyj-commands

Slash 命令注册表与内置命令（/help、/compact 等）

crates/mcp · wyj-mcp

MCP 客户端桥接（stdio / http 传输）

crates/store · wyj-store

Extension 安装与 lockfile、Plugin runtime 事务激活、持久 LSP client、schedule

crates/i18n · wyj-i18n

多语言资源与运行时语言切换

核心层 · Core

crates/core · wyj-core

Agent、Session runtime/events、权限、checkpoint、workspace/workflow 接口与本地 CodeIndex

基础层 · Foundation

crates/api · wyj-api

LLM Provider 抽象 trait + Anthropic/OpenAI 双格式实现，SSE 流式解析

crates/config · wyj-config

配置加载（~/.wyj-code/config.toml）、MCP 配置结构

crates/sandbox · wyj-sandbox

Seatbelt / bubblewrap 命令隔离、凭证 deny-read 与域名级网络边界

Install

60 秒上手

一条命令完成下载、安装、配置 PATH，无需 sudo / 管理员权限。

macOS / Linux

curl -fsSL https://wangyooujin.github.io/wyj-code/install.sh | sh

Windows (PowerShell)

irm https://wangyooujin.github.io/wyj-code/install.ps1 | iex

脚本自动识别平台架构、拉取 GitHub 最新 Release、校验 sha256 后装入用户目录；之后可用 wyj-code update 升级。

手动从 GitHub Releases 下载对应平台压缩包，解压后运行内置安装脚本——这正是上面一键脚本在背后做的事，适合不想执行 curl | sh 的场景。

# macOS / Linux
tar xzf wyj-code-*.tar.gz && cd wyj-code-*/ && ./install.sh

# Windows（在解压目录里）
install.bat

# 之后升级
wyj-code update
前往 Releases 页面下载 →

需要 Rust 1.80+ 工具链，构建 release 二进制并安装到 ~/.local/bin。

git clone https://github.com/wangyooujin/wyj-code.git
cd wyj-code
./build.sh install

# 卸载
./build.sh uninstall

直接用 cargo 跑起来，适合改代码调试。

# TUI 模式
cargo run

# 单次问答
cargo run -- -p "你的问题"

# headless REPL
cargo run -- --headless

# 查看配置状态
cargo run -- --config-status

Principles

设计原则

01

本地优先

没有隐式埋点、没有崩溃上报，配置与会话数据全部留在本机。

02

透明可控

每一次工具调用全程实时展示，敏感操作前弹权限确认，随时可以 ESC 打断。

03

协议中立

vendor 与 wire protocol 分离，同一兼容协议可服务不同厂商，不把模型名称猜测当成最终事实。

04

零遥测

只有显式的 LLM / WebFetch / MCP 调用才会出网，没有任何后台上报。
