wyj-code 处理流程

从进程启动到一次完整问答的端到端链路：CLI 装配 Agent，Agent 每轮把「stable 系统提示 + 工具清单 + 历史」交给 provider， 流式回收文本与 tool_use；有 tool_use 就进工具轮（权限闸门 → 执行 → 结果回填），没有就收尾落盘； TUI 只负责渲染 core 的事件流并回收用户输入。
