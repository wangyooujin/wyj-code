## 1. 目标

保留已经完成的全部 P1/P2、国内模型多工具调用兼容、ToolSearch 核心执行面保底和固定 Rust 1.96 CI，仅修复发布资产 checksum 的跨平台换行边界，并把实物校验变成 Release 的硬门禁。

同时将 `window_capture`、`app_computer` 和已注册的兼容 `computer` 纳入 lazy schema 常驻核心集，确保国内模型始终能看到主提示词要求的稳定窗口发现与后台动作入口；未注册工具不会凭空出现，权限边界不变。

## 2. 根因与修复

- 根因：Windows PowerShell `Out-File -Encoding ascii` 生成 CRLF sidecar；Linux 聚合时直接 `cat`，导致 `SHA256SUMS` 的 Windows 文件名尾部保留 `\r`。
- Windows 打包改用 `System.IO.File.WriteAllText` 明确写 ASCII + LF，无 BOM。
- 聚合时使用 `sed 's/\r$//'` 防御历史/第三方 sidecar 的 CRLF。
- Publish Release 在上传前执行 `sha256sum --check SHA256SUMS`；任何归档内容、sidecar 或聚合错误直接失败。
