# wyj-code v1.2.1 计划

## Summary

v1.2.1 是补丁级体验与兼容性版本，目标是：

- 重构 TUI 信息流：AI thinking/回答直接显示；工具结果、Bash 输出、Write/Edit diff 等默认只显示概要，选中后 `Ctrl+O` 展开/收起。
- 改进国内模型兼容：首批聚焦 GLM + MiniMax，通过 Profile 能力开关保守处理第三方 Anthropic/OpenAI-compatible 端点。
- 提升 token 观测：补充 full input/cache hit/context 指标，并把自动压缩缓冲从固定 40K 改为按窗口动态计算。

本版优先满足“完整历史可选中展开”，因此 TUI 聊天主视图从终端原生 scrollback 冻结策略切换为应用内完整消息流滚动。

## Key Changes

- TUI 消息流：
  - 每条 `ChatMessage` 分配稳定 `id`，`AppState` 维护 `selected_message_id`、`chat_scroll`、`chat_follow_tail`。
  - `Up/Down` 在输入框为空时遍历可展开概要消息；`Ctrl+O` 展开/收起当前选中项。
  - `Command+Up` 跳到当前会话开头；`Command+Down` 跳到最新消息。
  - `MessageRole::Thinking` 直接进入消息流，不再折叠成一行统计。
  - ToolCall 与对应 ToolResult 合并为单个紧凑工具块；BashOutput 默认单行概要，展开后显示完整输出或 diff。
  - 移除运行时 `Terminal::insert_before` 冻结主路径，避免历史消息展开后无法重绘。

- 国内模型兼容：
  - `Profile` 新增 `prompt_cache: Option<bool>` 与 `openai_stream_options: Option<bool>`。
  - 官方 Anthropic/OpenAI 端点默认开启对应优化字段；第三方兼容端点默认关闭，用户显式配置优先。
  - GLM 模板默认 `glm-5.2`、`prompt_cache = false`、`vision = false`。
  - MiniMax 模板默认 `MiniMax-M2`、`openai_stream_options = false`、`vision = false`。
  - `/model` 面板暂不暴露高级字段，但保存时完整透传。

- Token 观测：
  - 新增 `compact_trigger_buffer(context_window) = min(40000, max(4000, context_window / 5))`。
  - `WYJ_STATS_JSON=1` 增加 `full_input_tokens`、`cache_hit_ratio`、`context_tokens`、`context_window`。
  - `/cost` 增加 full input / uncached input / cache hit ratio。
  - `benchmarks/compare.sh` 增加新指标列，并兼容旧 jsonl 缺字段。

## Tests

- `cargo check --workspace`
- `cargo test --workspace`
- `cargo clippy --workspace --all-targets`
- `cargo fmt --check`
- 手测 TUI：
  - 长历史中选择任意工具结果，`Ctrl+O` 展开/收起，确认无重影和遮挡。
  - 并发工具调用结果仍紧跟自己的 ToolCall。
  - thinking 与 assistant 正文按消息顺序显示。
  - 鼠标滚轮可滚动应用内历史；`Command+Up/Command+Down` 跳转当前会话首尾。
- 可选网络 smoke：
  - GLM：纯文本 + 只读工具调用。
  - MiniMax：纯文本 + 只读工具调用。

## Assumptions

- v1.2.1 不把 `/model`、`/mcp`、`/skills` 等管理面板改为内联消息。
  唯一例外：`/agents` 升级为 TUI 交互对话框，列表 + 详情双视图与现有
  `/skills`/`/mcp`/`/plugins` 面板对齐；headless 退化为纯文本（沿用原输出）。
- 权限确认、AskQuestion、Plan approval 本版继续使用现有底部交互区域，但不得遮挡聊天消息流。
- GLM/MiniMax 以保守兼容为先；高级能力需要真实 key smoke 后再逐项打开。
- 动态工具裁剪、价格表外置、fallback profile 等更大改动留到 v1.3。

## 增补（amend 批次）

- TUI 交互：`/agents` 从一次性纯文本输出升级为 `OpenAgentsDialog`（列表/详情
  双视图，独立按键拦截块不进入通用 ui_focus 路由），与 `/skills`/`/mcp`
  `/plugins` 面板一致；headless 走 fallback_text 保持纯文本兼容。i18n 增补
  agents 对话框标题与重载提示的中英文条目。
- 子 Agent 工具白名单：抽出纯函数 `select_sub_agent_tools(def, registry)`
  按 `AgentDefinition.tools` 字段过滤；`None` 表示不限制。cli 装配时一并
  在 rebuild_fn 里复用，使 `/model` 切换 Profile 后子 Agent 仍按当前定义
  的白名单生效。`cli/Cargo.toml` 补 `async-trait`/`serde_json` dev-dep。
- MCP 工具共享快照：新增 `wyj_tools::SharedMcpTools = Arc<RwLock<Vec<Arc<dyn Tool>>>>`，
  三种模式（`-p`/`--headless`/TUI）连上 MCP 时 push；`/model` 重建 ToolRegistry
  前回灌，避免此前会清空后台 MCP 工具的 bug；子 Agent 工厂共享同一快照，
  确保 spawn 时刻看到的是当前进程内已连好的 MCP 工具集。
- 导航焦点：移除旧的滚轮防抖（`is_deliberate_up_down_press`），改为基于
  `selected_message_id` 的 `move_focus_selection(delta)`，Up/Down 按 UiFocus
  分流到 Todos/SubAgents/Chat；新增 `TodoExecutionEntry` 关联 Todo 与消息
  流事件，便于面板汇总统计。`tui/CLAUDE.md` 同步更新 Esc 分层退出语义。
